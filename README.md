# FBL Visual Novel Cutscenes 1.6.8

Модуль для Foundry VTT v13, добавляющий редактор и синхронный полноэкранный плеер катсцен в стиле визуальных новелл. Целевая среда: Foundry VTT 13.351 и Forbidden Lands 13.0.5.

## Возможности

- ApplicationV2-редактор катсцен с частичным рендером интерфейса.
- Реплики, наррация и кадры выбора.
- Несколько текстовых блоков и отдельная озвучка каждого блока.
- Форматирование текста внутри блока: жирный, курсив, подчёркивание, зачёркивание, индексы, шрифт, размер, цвет, подсветка, выравнивание и списки.
- Два режима показа текста: обычная диалоговая панель и центральный текст без видимого блока.
- Для каждого кадра можно выбрать виньетку: автоматическую, экранную, локальную вокруг текста или полностью отключить её. Новые кадры по умолчанию создаются без виньетки; автоматический режим остаётся доступен и использует экранную виньетку для обычной панели и компактное затемнение вокруг центрального текста.
- Новые кадры по умолчанию создаются без перехода между фонами/портретами; Fade и затемнение включаются только явно.
- Обычная диалоговая панель закреплена у нижней границы экрана и имеет постоянную высоту; длинный текст прокручивается внутри панели.
- Новые кадры и новые пресеты персонажей по умолчанию размещают портрет слева. Выбранная в кадре позиция сохраняется и не перезаписывается при применении пресета персонажа.
- Один кадр может показывать несколько персонажей одновременно. Дополнительные персонажи добавляются кнопкой «Добавить персонажа», для каждого отдельно выбираются пресет, портрет, имя, позиция слева/по центру/справа и видимость имени. В режиме центрального текста имена, как и раньше, не выводятся.
- Основной персонаж сохраняет прежнее поведение наследуемого портрета между кадрами; дополнительные персонажи принадлежат конкретному кадру и исчезают при переходе на кадр, где они не добавлены.
- В менеджере пресетов персонажи по умолчанию свёрнуты в компактные строки с именем и числом портретов; раскрытие показывает настройки и полный список портретов. Раскрытое состояние сохраняется при добавлении или удалении портретов в текущем окне, а длинный список снова прокручивается внутри окна.
- Портрет персонажа опирается нижней кромкой на верхнюю границу панели, а компактный блок имени соприкасается с панелью и выравнивается по её левому/правому краю для крайних позиций.
- Локальная кнопка скрытия расположена рядом с «Продолжить» и убирает обычную текстовую панель, имя, варианты выбора, портрет персонажа и виньетку; отдельная кнопка возвращает интерфейс.
- Варианты выбора отображаются отдельным списком по центру экрана, вне текстовой панели.
- В режиме центрального текста кнопка «Продолжить» и состояние ожидания остаются в обычной нижней правой позиции и не сдвигаются вслед за текстом.
- Фоны, портреты, многоканальная музыка, многоканальные SFX и переходы между кадрами.
- Аудиомикшер кадра поддерживает одновременное воспроизведение нескольких музыкальных и SFX-каналов, замену или остановку отдельного канала, остановку всей группы и независимое зацикливание.
- Ветки сюжета, вложенные папки кадров и drag-and-drop сортировка.
- Отдельные менеджеры ассетов, персонажей и счётчиков.
- Условия и эффекты счётчиков в вариантах выбора.
- Любой кадр может увеличить или уменьшить выбранный счётчик при входе в кадр; эффект применяется один раз на вход и затем учитывается условиями этого же кадра.
- Условный следующий кадр с отдельными исходами «Если да» и «Если нет».
- Граф связей, поиск входящих ссылок и встроенная проверка сцены. Компактный режим переключается через ApplicationV2 action-кнопку с явным рендером `main` part, скрывает линейные кадры независимо от переходов между editor-ветками и использует отдельную плотную временную раскладку, не смешивая её с сохранёнными координатами полного графа; видимыми остаются старт, выборы, финалы, реальные условные развилки и необходимые anchors циклов. Автораскладка учитывает циклы и возвраты между ветками: strongly connected components раскладываются детерминированно по колонкам, ветки получают отдельные вертикальные полосы, а обратные переходы рисуются через отдельный правый канал вместо огромных кривых.
- Импорт и экспорт JSON.
- Индивидуальное чтение, синхронное ведение ГМом и голосование игроков.
- При запуске катсцены блокируется только на небольшом стартовом окне: текущий кадр и до двух уровней ближайших прямых, условных и choice-переходов, максимум 12 кадров. Остальные изображения прогреваются в фоне по одному файлу одновременно, а nearby-прогрев использует не более двух параллельных запросов, оставляя браузеру запас соединений для критического кадра и аудио.
- Аудио всей большой сцены больше не предзагружается целиком: стартовый буфер ждёт музыку/SFX и только непосредственно нужный voice каждого ближайшего кадра. После входа в кадр остальные его voice-блоки прогреваются в фоне; voice следующего текстового блока при необходимости загружается перед его показом. При входе в ещё не прогретый кадр его непосредственно нужные ассеты получают приоритет.
- Раздельная локальная громкость музыки, голосов и SFX.

## Открытие редактора

Редактор доступен в настройках модуля. Его также можно открыть макросом:

```js
game.fblVN.openEditor()
```

Основные методы API:

```js
game.fblVN.openEditor()
game.fblVN.preview(sceneId)
game.fblVN.play(sceneId)
game.fblVN.getScenes()
game.fblVN.getScene(sceneId)
game.fblVN.diagnostics()
```

Операции редактирования и запуска катсцен доступны только ГМу.

## Структура редактора

Слева расположен список катсцен. В центральной колонке находится дерево кадров выбранной ветки. Внизу дерева расположен блок управления ветками:

- `+` создаёт новую ветку;
- карандаш переименовывает текущую ветку;
- копирование дублирует ветку вместе с папками и кадрами;
- корзина удаляет ветку с переносом либо удалением её содержимого.

Правая часть окна содержит параметры сцены и форму выбранного кадра. Редактор разделён на семь независимых ApplicationV2 parts, поэтому частые действия обновляют только затронутые области и сохраняют прокрутку остальных панелей.

## Счётчики и условные переходы

Счётчики сцены открываются отдельной кнопкой в шапке редактора. Они существуют только внутри одного прохождения текущей катсцены.

Вариант выбора может:

- отображаться только при выполнении условия счётчика;
- увеличивать или уменьшать выбранный счётчик.

Любому кадру — реплике, наррации или выбору — можно отдельно назначить изменение счётчика. Оно выполняется один раз при входе в кадр, до последующей проверки перехода.

В блоке «Следующий кадр» можно включить «Проверку счётчика». Обычный переход заменяется сравнением и двумя целями: «Если да» и «Если нет». Обе цели выбираются тем же поиском по кадрам, что и обычный следующий кадр. Пустая цель означает переход к следующему кадру по порядку. Флаг «Финал» завершает катсцену без выполнения перехода. Переключение режима происходит локально внутри панели и не перерисовывает ApplicationV2-редактор целиком. Перед изменением высоты блока редактор снимает фокус со скрытого checkbox, сохраняет scroll позиции панели и текущую геометрию ApplicationV2, а затем восстанавливает её через setPosition после layout-пересчёта. Это не даёт браузеру или ApplicationV2 расширить и сдвинуть окно при раскрытии условного маршрута.

## Хранение и перенос данных

Сцены, ассеты и персонажи хранятся в служебном `JournalEntry` с ownership `NONE` для обычных игроков. Создание и первичная миграция этого Journal выполняются только активным GM (`game.users.activeGM`), чтобы два GM не создали два независимых хранилища при одновременном входе. Старый скрытый world setting сохранён только как миграционный источник: при первом запуске версии 1.0.1 или новее под активным GM данные переносятся в Journal и legacy-хранилище очищается. Если после `ready` приватное хранилище недоступно, запись блокируется с ошибкой вместо небезопасного отката к world setting. Перед крупными изменениями рекомендуется использовать «Экспорт всего». Импорт поддерживает полный экспорт модуля, массив сцен и отдельную сцену.

Старые данные автоматически проходят миграции до актуальной схемы. Резервные поля старых версий не сохраняются обратно после нормализации. Полная сцена всё ещё передаётся участникам через модульный socket при запуске, поэтому module socket не следует считать каналом для секретных данных от технически недоверенного клиента.

## Предзагрузка больших катсцен

Старт больше не ждёт загрузку всех ассетов сцены. Клиент сначала подготавливает ограниченное окно вокруг стартового кадра: сам кадр и до двух уровней потенциальных переходов, включая обе стороны проверки счётчика и явные переходы вариантов выбора. Окно ограничено 12 кадрами, чтобы сцена с большим ветвлением не превращала старт в полную загрузку.

Перед `ready` клиент дополнительно перепроверяет непосредственно необходимые ассеты стартового кадра и завершает рендер экрана загрузки, чтобы команда старта не могла пересечься с незавершённым loading-render. После этого в фоне с низкой конкуренцией прогреваются остальные изображения сцены. Для текущего кадра прогреваются все его voice-блоки, но у будущих кадров заранее берётся только входной voice, поэтому десятки длинных реплик не блокируют старт. При смене текстового блока нужный voice при необходимости загружается непосредственно перед показом. Если критический файл временно не загрузился, выполняется повторная попытка; после повторной ошибки переход всё равно продолжается, а браузер получает обычную возможность загрузить ресурс при отрисовке или воспроизведении.

Настройка «VN: ожидание предзагрузки» ограничивает ожидание ГМом готовности именно стартового буфера других клиентов, а не всей катсцены. Переходы, пришедшие по сети во время старта или восстановления переподключившегося клиента, буферизуются и затем полностью проигрываются по порядку через общую playback-очередь.

## Настройки игрока

В настройках модуля доступны:

- громкость музыки;
- громкость голосов;
- громкость SFX;
- отключение анимаций;
- мгновенный показ текста.

Эти параметры client-side и не меняют настройки других участников.

## Проверка сборки

Из корня модуля:

```bash
node tools/verify.mjs
node tests/smoke.mjs
node tests/boot-smoke.mjs
```

Проверка контролирует manifest, относительные импорты, ApplicationV2 parts, Handlebars actions, действия панели веток, CSS ownership, число `!important` и отсутствие резервных файлов.
